# address channel: scam vs spam

the address analog of spam is unsolicited bulk physical mail; the
address analog of scam is fraud shaped around a location. the more
common question here is the scam side:

- **freight-forwarder abuse**: reshipping and parcel-mule scams route
  stolen goods through freight forwarders and parcel lockers; the
  shape intelligence maintained on the `thelocaletell` branch (po box
  equivalents, carrier lockers and pickup points, cmra/virtual
  mailboxes, freight forwarders) is the evidence base
- **mule and money-drop addresses**: repeated-use drop addresses and
  virtual mailboxes in fraud patterns; repetition and clustering is
  adapter/analyst evidence, not shape evidence, and stays separate
- **fabricated addresses**: the apartment-f case; address_existence
  disconfirmation via the smarty adapter (match code S, footnote C1)
  is exactly this channel's work

honest limits stated up front:

- a mailbox shape is not intent. millions of people use po boxes,
  lockers, and virtual mailboxes legitimately. shape findings organize
  *what an address is*, never *what a person is doing with it*
- intent patterns (drop-address repetition, goods-trafficking
  sequences) require investigation-grade evidence the offline core will
  never fabricate; they enter as adapter signals with provenance or not
  at all
- unsolicited bulk physical mail (address spam: junk mail, saturation
  advertising) is volume evidence; the component can classify the
  shapes but volume claims need campaign-level data, stated honestly
  as a coverage gap
